补 _headers：本站此前完全没有响应头配置

实测发现：universe 是**唯一没有 `_headers` 的站**，后果不只是没缓存 ——
连安全头也是 0/4。对照 blog（9 条规则 / 安全头 4/4）后来补的。

实测缺口（部署前）：
  /css/style.css      public, max-age=0, must-revalidate   ← 每次回源
  /js/app.js          public, max-age=0, must-revalidate
  /fonts/*.woff2      public, max-age=0, must-revalidate   ← 700 KB！
  安全头              ❌ 0/4

本次补齐：
  · 四个安全头（照搬 blog / gear 的设计）
  · /fonts/*.woff2 → 一年 immutable（5 片共约 700 KB，文件名是语义名、
    内容不会原地变）
  · /css/* 与 /js/* → 300s（**本站 index.html 不带 ?v= 指纹**，
    与 gear 不同，所以不能 immutable，否则改版后访客永远刷不掉）
  · index.html / 404.html 故意不写规则，落 Cloudflare 默认的
    max-age=0, must-revalidate（HTML 要的就是「每次回源校验」）

自查（用 wrangler 真实实现逻辑模拟匹配，非自写近似）：
  · 覆盖 8/10，未覆盖的正是那两个 HTML（有意）
  · 规则重叠 0 处（Cloudflare 会把重叠规则的 Cache-Control 拼接、
    浏览器只认第一个，长缓存会被静默吃掉 —— 这条守住了）

部署后线上实测：
  /css/style.css       → public, max-age=300
  /js/app.js           → public, max-age=300
  /fonts/*.woff2       → public, max-age=31536000, immutable
  安全头               → 4/4 ✅
